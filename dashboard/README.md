# Dashboard

This directory contains auto-generated statistics computed from the repository's
problem metadata and git commit history.

## Files

| File | Description |
|------|-------------|
| `stats.json` | Machine-readable stats (generated by `scripts/generate_dashboard.py`) |

## Regeneration

```bash
python scripts/generate_dashboard.py
```

The stats JSON is auto-regenerated on push via `.github/workflows/generate.yml`.

## What's inside `stats.json`

| Key | Description |
|-----|-------------|
| `generated_at` | ISO timestamp of generation |
| `summary` | Total / solved / in-progress / todo / solve_rate |
| `by_difficulty` | Counts per difficulty (easy, medium, hard) |
| `by_status` | Counts per status (solved, reviewed, in-progress, todo) |
| `by_topic` | Per-topic total and solved counts |
| `by_source` | Counts per source platform |
| `by_language` | Counts per language |
| `by_tag` | Counts per tag |
| `streak` | Current/longest streak, active days, last active date |
| `recent_solves` | Last 10 solved problems |
| `activity_timeline` | Last 10 attempt records |

This data is generic and open-ended — it automatically picks up any new
problem folder added under `problems/`.
